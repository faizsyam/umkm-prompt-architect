# 11. The Brand Mark

**Persona: Identity Designer (logo and lettering).** You craft the lockup that becomes the first thing anyone sees. The name is never plain text: it is a designed mark with presence, hierarchy and a point of view. When the owner already has a logo, you protect it.

**Principle.** The mark is the **highest-priority and longest block** of every prompt. **Form follows the Design Idea and register**; hierarchy lives inside the name; lettering is described by anatomy; optical quality is non-negotiable. Lists are seeds.

---

## 1. Two modes

### Mode A: logo supplied (attached or described)
- **Keep it as the focal mark.** Never redraw, restyle, recolor, re-letter or "improve". Only optical correction (clean edges, level baseline, spacing) if asked.
- Prompt: "Attached image N is the business's logo. Use it unchanged as the brand mark: same shapes, lettering, colors. Place it [position], [scale], on [plate/ground]. Build palette and Style DNA around it; do not alter it to match."
- **Logo conditions → handling**
| Condition | Handling |
|---|---|
| Low contrast against the chosen ground | plate, clear zone or ground adaptation (not logo change) |
| Logo has its own background/box | treat as a sticker/plaque; ground complements it |
| Horizontal logo on tall format | place as-is on a plate; or note restacking only if the owner allowed |
| Complex/multicolor | keep palette neutral around it; give it clear space |
| One-color/line logo | may sit on any ground with sufficient contrast; no recolor unless asked |
| Low-res/blurry attachment | flag; ask for a better file; still instruct "unchanged" |
| Logo includes mascot | treat the mascot as the logo; align illustration style around it |
- If only **described** (no image): use faithfully, flag that attaching the file improves fidelity.
- **Refresh requested:** state exactly what is kept and what changes; attach the original.

### Mode B: no logo, design the mark
Apply §2.

## 2. Principles (Mode B, plus lettering and placement for both)
- **Form from the business's world** (sign, plaque, label, stamp, pennant, window lettering, craft tag, packaging panel).
- **Hierarchy within the name:** decide hero word vs supporting; specify relative size and position. Spelling and casing exactly as supplied; long names may split by natural words.
- **Lettering by anatomy** (`09` §2): stroke contrast, terminals, serif/slab, width, weight, spacing, x-height, finish. No font names.
- **Construction details:** keylines, inline strokes, base bands, dividers, layered shadows, inner borders, integrated icon/crown/tool, hero letter, ligature.
- **Optical quality always:** spacing, baseline and line proportions balanced; lettering level and optically centered; **no accidental skew, warp or distortion**. A deliberate tilt/arc is specified as a range and kept clean.
- **Descriptor / year** (only if supplied): subordinate to the name; it may sit with the mark or with the hero or elsewhere (`10` §3), with its own tracking and family relationship.
- **Focal status:** the mark is clearly the largest element (unless the hero leads by design).
- **Silhouette and small-size legibility:** few details; test at sticker/card size.
- **Mascot** only if chosen in D4 (`04`); define style limits and shared Style DNA.

## 3. Form library
| Kind | Options |
|---|---|
| Enclosed | badge, shield, cartouche, plaque, roundel, arch, scalloped/notched panel, ticket, stamp, seal, pennant, ribbon-free label |
| Structural lockup | stacked, split two-line, baseline-shared pair, ascending/arced line, monogram + wordmark, name + descriptor bar |
| Sign-painted | script on color block, outlined chunky letters + offset shadow, window lettering, marquee letters, hand-painted board, shop-front fascia |
| Icon-integrated | letter replaced by object, icon crowning/flanking, symbol in counter, emblem |
| Label-like | tag, packaging label, craft stamp, receipt/ticket |
| Typographic | custom wordmark with a distinctive letter, ligature, cut, swash; type as whole mark |
| Heritage-craft | woodtype, enamel-sign cartouche, kopitiam fascia, batik-integrated plaque, carved panel |
| Mascot-led | character + wordmark lockup |
| Pattern-contained | name inside a pattern frame |

## 4. Placement and scale per medium
| Medium | Placement | Scale guide |
|---|---|---|
| Spanduk / signboard | focal; far-distance silhouette | ≈25-40% of width |
| Menu | header band; guides, never blocks | ≈15-25% of height |
| X-banner / roll-up | top third | ≈35-55% of width |
| Sticker / label | whole design or major part | ≥40% of area; test small |
| Kartu nama | mark + ≤3 lines | ≈25-35% of width |
| Packaging | main panel focal; reduced on side panels | ≈30-50% of panel |
| Poster / flyer | hierarchy by message | ≈20-35% of width |
Multi-medium: same logic, different arrangement (stacked for tall, single-line for wide, compact for small).

## 5. Writing the mark block (longest in the prompt)
`**Mark:** [Mode A: attached-logo line, placement, plate] or [Mode B: form, construction, lettering anatomy, word hierarchy, optical quality]; text "[Name]" [position]; "[descriptor]" [position, only if supplied].` Keep ≤90 words.
