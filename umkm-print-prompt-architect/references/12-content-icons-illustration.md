# 12. Content, Icons, Illustration, Decoration, Elements

**Persona: Illustrator & Information Designer.** You make content modules that deliver the offer, the USP and the information clearly, in one hand-drawn language. You design icons and info blocks so every contact detail is understood without label words. Decoration adds personality, never clutter.

**Principle.** Every module **shares the Style DNA**, has a **rank** in the hierarchy and a stated **relationship to the focal point**. Include only what the request, the USP and the owner's D4 choices need. All lists are **seeds**: choose by job and constraints, or invent.

## 1. Element library (source for D4 options and content modules)
| Element | What it is / options | Effect | Suits | Watch |
|---|---|---|---|---|
| **Hero illustration** | one subject with strongest appeal: cutaway, stacked, overflowing, in-use, overhead, three-quarter, close crop, lineup (§3) | instant recognition, appetite | any product-led | cliché stock look |
| **Photo-referenced depiction** | uses attached product photo as structural reference, drawn in illustration language | accuracy | when photos exist | never claim photographic |
| **Showcase set** | 3-6 featured items, equal structure, distinct color identity, exact labels; row, staggered, fan, tiers, spotlight+supports, grid | variety, menu preview | many items | label legibility |
| **Mascot / character** | animal, object-person, human figure, abstract blob; in Style DNA | personality, recall | youth/family/kids/snack | childish mismatch; fidelity if logo has one |
| **Owner/staff portrait** | stylized in illustration language; attire accurate | trust, personal brand | home/family business | likeness accuracy; permission |
| **Hands/action scene** | pouring, cooking, folding, handing over | craft, ritual | craft, kafe, bakery | hand anatomy (keep stylized) |
| **Regional motif / pattern** | named heritage motif (`07` §6) | rooted identity | regional/traditional | pastiche |
| **Pattern field / background** | repeat motif as ground or band | richness, cohesion | packaging, banners | text on pattern |
| **Ornament / decoration** | heritage, thematic, punctuation, anchors, texture (§4) | personality | per density | clutter |
| **Price/promo badge** | chip, tag, stamp, burst, plate; only with supplied data | action, value | promo, menu | cheap look if overused |
| **QR plate** | attached QR placed unaltered, or blank flat plate | action | any digital link | never draw a fake QR |
| **Icon set** | contact + service/attribute icons in Style DNA (§2) | clarity | all | consistency |
| **Typographic-led** | type as the image; no hero illustration | boldness, low cost | strong names/slogans, small formats | needs strong type |
| **Texture / grain** | paper, print noise, ink | craft feel | handmade, vintage | muddying text |
| **Occasion/seasonal cue** | Ramadan/Lebaran, Imlek, 17-an, grand opening, promo | timeliness | seasonal | cultural fit; limited shelf life |
| **Tagline emphasis** | typographic treatment of a supplied/approved line | memory | any | only approved text |
| **Official marks** | halal, PIRT, BPOM, QRIS only as attached images, unaltered | trust | when real | never drawn from imagination |

**Content-module rules**
- **Info block:** one aligned group; icon + value (§2); consistent line spacing; flat plate if overlapping artwork; separators only if wanted.
- **Tagline:** typographic treatment tied to hierarchy (line break, emphasis word, color, ornament), not a caption; supplied/approved only.
- **Price/promo:** exact supplied strings; format as supplied ("15K" vs "Rp 15.000").
- **QR:** image models can't generate valid codes: attached image placed unaltered on a clean plate with quiet space, or a **blank flat empty plate** (no pattern, no fake code); state which.

**Rules:** icons share Style DNA (contour weight, edge language, fill) · one consistent size aligned to a shared axis/column · icon **before** its value · recognizable but generic; no exact brand logos; no letters inside except natural "f"/"P" · never print "WA/WhatsApp/IG/Instagram/Alamat/Telp/Jam" as labels or add "Follow us/Hubungi" unless supplied · handles exactly as supplied ("@kopisenja") · small media ≤3 icon-value rows; large banners: icons ≈1.2× text cap height · in the prompt's TEXT block include **values only**; describe icons in the info-block paragraph; add to Exclusions "no label words such as WA, IG, Alamat, Telp".

## 3. Illustration language (one for the whole piece)
**Principle:** every illustration looks drawn by one hand and fits the register. Choose **one technique** and specify parameters (contour weight, fill logic, texture, detail density, proportion character, shadow logic, imperfection). No gradients unless the technique demands it (then name it), no photorealism, no 3D shading; imperfect and human, never sterile clip-art. Match technique to register (precision for calm, expressive contour for playful, texture for street) and detail density to viewing distance. If photo-based is deliberately chosen, state the rules.

**Technique library**
| Technique | Traits | Fits |
|---|---|---|
| Flat vector, confident line | uniform contour, flat fills | friendly, universal |
| Flat vector, thin line | refined | calm, premium |
| Outline-free flat shapes | color-only forms | modern, graphic |
| Paper-cut collage | layered shapes, hard shadow | playful, handmade |
| Linocut / woodblock | carved contour, 1-3 inks | rooted, craft |
| Risograph / screen-print layers | spot inks, misregistration | indie, street |
| Sticker-style bold contour | thick outline + die-cut keyline | youth, snacks |
| Hand-painted signboard brush | brush strokes, outline, drop shadow | warung, gerobak |
| Engraving / etching | fine hatching | premium-heritage |
| Naive folk | simple, decorative, flat | regional, family |
| Halftone poster | dot shading, bold | pop, street |
| Cut-paper dimensionality | stacked layers with hard shadows | desserts, kids |
| Chalk / marker | textured strokes | cafés, specials |
| Gouache-like flat painterly | soft edges, flat shapes | artisanal |
| Block / grid (pixel-like) | modular cells | retro-digital |
| Monoline icon-style | single stroke | minimal, labels |
| Batik-line | wax-resist outlines with dots/hatches | batik/regional |
| Stencil | cut-bridges, flat | street, workshop |

**Hero depiction library (views):** overhead · three-quarter · cross-section / cutaway · stacked tower · overflowing container · mid-action (toss, pour, flip) · in-hand · close crop · lineup of variants · exploded components · before→after · scene vignette (counter, stall) · macro texture · silhouette on stage shape.

**Appetite rules for food:** show structure (layers, cross-section, texture) · abundance suited to the offer · warm food colors against a ground that makes them glow · clear hero silhouette · believable portions · hand-cut highlight shapes instead of gloss gradients · steam/drops sparingly and flat.

**Non-food products and services:** show the **thing and its use** (tool in hand, folded stack, product in packaging) with believable proportions · show the **outcome** (clean, finished, repaired) · keep people stylized and optional.

**People and mascots:** stylized, culturally accurate attire/props; no fake celebrity likeness; mascot types: animal · object-person · human figure · abstract blob · product-as-character; set limits (simple, consistent proportions, few colors); share Style DNA.

## 4. Decoration
**Principle:** each piece has a **purpose, placement rule and cap**; scale quantity to the density dial; tie each accent to the offer, heritage cue or connector; group by logic; keep clear space around the mark and info; never touch info text; state a restraint clause.

**Tier library**
| Tier | Options |
|---|---|
| Heritage / pattern | tone-on-tone motif, trim, tassel, fretwork, ornament band, tile fragment, hand-block patch |
| Thematic | ingredients, tools, packaging, plants, steam, drops, crumbs, utensils; grouped near the hero or set |
| Punctuation | sparkles, dots, stars, bursts, asterisks, dashes, sprigs, swirls, motion ticks; one family, sparse, shared direction |
| Anchors | stage shapes, cushions, boards, shadows, grounds under/behind elements |
| Texture | grain, halftone, paper fibres, print noise, ink bleed, fabric weave |
| Dividers/frames | rules, double rules, dotted leaders, scalloped band, ribbon-free banner, corner brackets, arch frame, plate |
| Background treatments | flat, two-tone split, soft zones, pattern mask, stage shape, rays, grid, stripes |
| Badges | seal, starburst (use sparingly), ticket, ribbon tag, round sticker |

**Budget by density:** spacious ≈4-6 accents · balanced ≈8-12 · rich ≈12-20 · abundant ≈20-30 (still grouped).
