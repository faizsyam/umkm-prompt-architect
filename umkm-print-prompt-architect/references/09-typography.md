# 09. Typography

**Persona: Typographer & Lettering Artist.** You choose letterforms by personality and role, set hierarchy by contrast, and know how type behaves on a banner 10 m away and on a menu 40 cm away. You describe type by **anatomy**, not font names (models handle anatomy more reliably).

**Principle.** Type does two jobs: **personality** (display) and **legibility** (information). Use **two families** (three only for a script accent), assign by **role**, pair through **contrast of role**, state hierarchy as a **ranking**. All lists are **seeds**.

---

## 1. Principles
- Two families by role and personality, described by anatomy.
- Pair by **contrast of role** (display vs reading), not by two similar faces.
- Hierarchy as ranking (1 mark, 2 tagline, 3 category, 4 item, 5 price, 6 contact).
- Specify tracking, leading, weight, case, alignment.
- **No hairlines** at distance; thin strokes vanish on flexi.
- State tone and exclusions (no novelty fonts, no warped letters).
- Respect the language: Indonesian words can be long; print as supplied; no added diacritics.
- Numerals: lining, tabular for prices; same style down a column; "Rp", "K", ".000" exactly as supplied.

## 2. Anatomy vocabulary
Stroke contrast (high/low/monoline) · stress axis · terminals (flared, ball, cut, rounded, squared) · serif structure (bracketed, unbracketed/slab, wedge, hairline) · width (condensed/normal/extended) · weight (light → black) · x-height (low/high) · ascender/descender length · counters (open/closed) · apertures · letter-spacing (tight/normal/tracked) · leading · case (all-caps, small caps, title, lowercase) · finish (clean, hand-cut, inked, brushed, stenciled, outlined, inline, shadowed, textured) · optical alignment · ligature · swash · alternates.

## 4. Role seeds
| Role | Options |
|---|---|
| Display / mark | sturdy flared serif · soft slab · high-contrast serif · chunky rounded serif · wedge serif · signwriter script · brush script · condensed gothic · stencil · geometric display · hand-cut block · outlined/inline display · custom wordmark |
| Supporting / descriptors | tracked small caps · humanist sans · geometric sans · rounded sans · grotesque · italic serif · monoline script · typewriter |
| Information | humanist sans · neo-grotesque · condensed sans · rounded sans · low-contrast text serif |
| Price | tabular lining numerals, medium/bold weight, distinct from item name |
| Accent | script or handwritten for one phrase only |

## 5. Pairing mechanisms
Contrast of structure (serif + sans; script + sans; condensed + wide) · same superfamily in different weights (safest) · one expressive + one neutral (expressive for mark and one accent) · match **register**: calm → refined serif + light sans; spirited → chunky display + friendly sans; street → condensed/brush + plain sans; heritage → sturdy serif + signwriter accent; premium → didone + geometric light.

## 6. Size, distance, spacing
| Viewing distance | Min key text height | Notes |
|---|---|---|
| 10 m+ | ≥40 cm (mark) | silhouette only |
| ~3 m | ≥2.5 cm per 3 m of distance | info on banners |
| Arm's length | item names legible, prices distinct | menus, cards |
Large media: bolder weights, wider tracking at small sizes. Small media: no fine serifs, avoid extreme condensing. Tracking: caps +4-12%, lowercase 0-2%, small sizes +2-5%. Leading: display 1.0-1.2, information 1.3-1.5. Line length for descriptions ≤40 characters.

## 7. Treatments
Outline · inline · offset shadow · long shadow · stamp/ink texture · cut-paper letters · drop cap · hero letter · ligature · arc/tilt (state angle; letters stay clean) · underline swash · bracket/rules · small caps for descriptors · all-caps for short labels only · knockout on plate · layered color fill · embossed look (flat tonal steps).

## 8. Information typography by product
| Product | Type system |
|---|---|
| Banner/spanduk | 1 display mark + 1 sans for contact; ≤3 levels |
| Menu | category (display/tracked caps) · item (medium) · description (light, supplied only) · price (tabular, distinct); dot leaders or aligned column |
| Price list | service name · unit · price column; icon per service |
| Sticker/label | mark + one descriptor; ≥2 levels only |
| Business card | name (display) · role (small caps) · values (sans) |
| Poster | headline (display) · subline · details |
Spice level/best-seller marks: small icons in the Style DNA, only if supplied.

## 9. Writing the type system in the prompt
"Two families. Display: [anatomy]. Information: [anatomy]. Hierarchy: 1 [mark], 2 [..], 3 [..]. Tracking [..], leading [..]. Tone: [..]. No hairline strokes, no novelty fonts, no warped lettering."
